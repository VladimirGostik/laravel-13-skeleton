## Architecture

```
HTTP request
  → web middleware (Locale → HandleInertiaRequests)
  → Controller (thin, autorizes via $user->can(...))
  → DTO (Spatie Data, validates via PHP attributes)
  → Service (final readonly, transactional, registered as singleton)
  → Model (Eloquent, LogsActivity, casts via casts() method)
  → DTO::fromModel for response
```

## Important quirks discovered during bootstrap

- **Laravel 13 Eloquent attributes**: only these exist — `Fillable`, `Hidden`, `Visible`, `Appends`, `Guarded`, `Table`, `Connection`, `DateFormat`, `ObservedBy`, `UseFactory`, `UsePolicy`, `Scope`, `ScopedBy`, etc. **`#[Cast]` does NOT exist** — use `casts()` method.
- **spatie/laravel-data + spatie/typescript-transformer v3 incompatibility**: `DataTypeScriptTransformer` references a removed `DtoTransformer` class. Use `AttributedClassTransformer` + `#[TypeScript]` on every DTO instead.
- **typescript-transformer config**: configured via `app/Providers/TypeScriptTransformerServiceProvider` (extends `BaseTypeScriptTransformerServiceProvider`); registered in `bootstrap/providers.php`. Override `outputDirectory(resource_path('js/types'))` because parent default is `js/generated`.
- **Vite v8 + plugin-vue v6**: incompatible (parse errors on `<script setup lang="ts">`). Pinned to `vite@^7` + `laravel-vite-plugin@^1`.
- **bootstrap/app.php → withEvents()**: only accepts `iterable|bool`, not Closure. Register listeners in `AppServiceProvider::boot()` via `Event::listen(...)`.
- **DaisyUI 5**: theme via CSS `@plugin 'daisyui/theme'` block (not config file).

## Files generated by tooling (do not edit by hand)

- `resources/js/types/generated.d.ts` — `php artisan typescript:transform`
- `public/build/**` — `pnpm build`
- `vendor/**`, `node_modules/**`, `composer.lock`, `pnpm-lock.yaml`

## CI

Bitbucket Pipelines (`bitbucket-pipelines.yml`):
1. Composer install
2. Pnpm install (frozen lockfile)
3. `php artisan typescript:transform` + `git diff --exit-code resources/js/types/generated.d.ts` (fails if DTO change wasn't committed with regenerated types)
4. Pint check
5. PHPStan
6. ESLint
7. Prettier check
8. vue-tsc
9. PHPUnit (sqlite in-memory)
10. Vite production build

## Pre-commit hooks (Lefthook)

- Pint on staged `*.php`
- PHPStan on staged `*.php`
- ESLint on staged `*.{js,ts,vue}`
- Prettier on staged `*.{css,json,md}`
- `php artisan typescript:transform` on staged `app/Data/**` or `app/Enums/**` + auto-stage `resources/js/types/generated.d.ts`

Pre-push: `pnpm typecheck` + `php artisan test --parallel`.
